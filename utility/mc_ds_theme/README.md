# mc_ds_theme

Light, dark, high-contrast and dark high-contrast (`McTheme.highContrastDarkTheme`) `ThemeData` (`McTheme`), the palette extension (`context.mcPalette`) and `McThemeModeController`.

## Bundled fonts and licences
- **Inter** (Regular, Medium, SemiBold, Bold), copyright (c) 2016 The Inter Project Authors, licensed under the **SIL Open Font License 1.1**. The licence text is in [`assets/fonts/OFL.txt`](assets/fonts/OFL.txt). Source: https://github.com/rsms/inter (release 4.0, `extras/ttf`).
- **MaterialIcons** is not bundled here; it comes from the Flutter SDK (Apache 2.0 / SDK licence).

The golden harness (real fonts, iOS platform, theme x text-scale matrix) lives in the test-only package `utility/mc_ds_testing`. See F-0014.
